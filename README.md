# Sentiment Analysis on Product Reviews

An end-to-end **NLP and Machine Learning project** that analyzes e-commerce product reviews and classifies customer sentiment as **Positive, Negative, or Neutral**.

## 🚀 Key Features

* Text preprocessing using **NLTK** — tokenization, stopword removal & lemmatization.
* Sentiment analysis using **VADER & TextBlob**.
* ML classification using **TF-IDF, Logistic Regression & Naive Bayes**.
* Model evaluation using **Accuracy, Precision, Recall & Confusion Matrix**.
* Customer sentiment, rating distribution & word-cloud visualizations.
* Interactive **Streamlit dashboard** for real-time review analysis.
* Supports custom product-review datasets.

## 🛠️ Tech Stack

**Python • NLP • NLTK • VADER • TextBlob • Scikit-learn • TF-IDF • Pandas • Matplotlib • Streamlit**
